# MSFS Plugin Manager

**A community plugin manager for Microsoft Flight Simulator 2020 / 2024.**

Scan your Community folder and organize every addon into clear categories — aircraft, liveries, scenery, and tools — with an interactive 3D globe view of airports.

> This repository is for **downloads only**. The source code is kept in a private repository.

## Download

Get the latest installer from the [Releases](https://github.com/stewieqi-del/msfs-plugin-manager-releases/releases) page.

## Features

- Scan and organize MSFS 2020 / 2024 community addons automatically
- Categories: aircraft, liveries, scenery, and tools
- 3D globe view with airport location filtering
- Light / dark theme and English / Chinese language support
- Built-in update check that pulls the latest release from this repository

## Requirements

- Windows 10 / 11
- Microsoft Flight Simulator 2020 or 2024 (optional — works with any Community folder)
